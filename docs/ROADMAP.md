# Дорожная карта

## Что реализовано

- Полный игровой движок: старт, узлы, выборы, таймауты, финальные узлы
- Защита от гонок через `FOR UPDATE` и проверку `version`
- Серверный таймер
- Аналитика компетенций с рекомендациями
- Профиль со статистикой прохождений
- Ачивки с условиями получения
- Уведомления о достижениях
- Лидерборд по общему счёту

## Что не реализовано

| Функция | Причина |
|---|---|
| Валидатор контента | Не хватило времени на хакатоне |
| Лидерборд на Redis | Упрощён до БД для надёжности |
| Уровни пользователя | Не хватило времени |
| Полная интеграция с фронтендом | Бэкенд-хакатон |

## Дальнейшие шаги

1. Добавить валидатор контента для проверки целостности сценариев
2. Реализовать систему уровней пользователя
3. Оптимизировать лидерборд через Redis при росте нагрузки
4. Добавить тесты для критичных путей (движок, ачивки)
