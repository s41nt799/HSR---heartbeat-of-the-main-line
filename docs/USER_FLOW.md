# USER_FLOW.md — Пользовательские сценарии

## Основной поток: Новая сессия

1. Переход по ссылке `/scenarios` — отображение списка доступных сценариев
2. Выбор сценария — нажатие на карточку сценария
3. Старт сессии — модальное подтверждение или немедленный переход на `/sessions/:id/play`
4. Игровой процесс:
   - Отображение текущего узла с текстом и шкалами loyalty/safety
   - Таймер на критических узлах (если deadline установлен)
   - Выбор варианта ответа (кнопки)
   - Автоматический POST /timeout при истечении дедлайна
   - Обработка выбора: показ toast-сообщения с эффектами
5. Завершение сессии:
   - Достижение ending_success или ending_fail
   - Нажатие кнопки «Завершить»
   - POST /finish → переход на `/sessions/:id/debrief`
6. Дебриф:
   - Итоговые показатели (state, loyalty, safety, score)
   - Разбор очков (base/speed_bonus/completion_bonus/penalty)
   - Список событий с типами (choice/timeout/finish/fail)
   - Критические решения и ошибки
   - Полученные ачивки
   - Рекомендации

## Повторная игра

1. Из дебрифа: нажатие «Ещё раз» → возврат к старту того же сценария
2. Или выбор другого сценария с нуля

## Профиль

1. Переход по ссылке `/profile` — отображение пользовательских данных
2. Секции: user info, level/progress, stats, recent sessions, achievements
3. Кнопка «Все ачивки» → `/profile/achievements`
4. Клик по recent session → `/sessions/:id/debrief`

## Лидерборд

1. Переход по ссылке `/leaderboard` — отображение топа игроков
2. Подсветка текущего пользователя
3. Возможность фильтровать по scope (если backend поддерживает)

## Демо-режим

1. Включение через флаг `VITE_DEMO_MODE=true` в env
2. Автоматическая настройка долгих дедлайнов (120 сек)
3. Предзаполненная медицинская сессия
4. Кнопка «Сбросить демо» для повторного запуска
