## Разделение ответственности

| Слой | Ответственность |
|---|---|
| Роуты | Приём запроса, вызов сервиса, возврат схемы |
| Сервисы | Бизнес-логика, работа с БД, транзакции |
| Модели | Структура данных, связи, ограничения |
| Схемы | Валидация входа, сериализация выхода |

Роуты **не** делают запросы к БД и **не** содержат бизнес-логику.

## Игровой движок

### Поток сессии

старт → узел → выбор/таймаут → переход → ... → финал

### Защита от гонок

Все изменения сессии используют `SELECT ... FOR UPDATE` для блокировки строки. Проверка `version` обеспечивает идемпотентность.

### Серверный таймер

Таймер рассчитывается на сервере через `deadline`. Клиент не может обойти таймер.

### Атомарность

Все изменения в рамках одной транзакции. При ошибке — полный откат.

## Аутентификация

- Пароли хешируются через bcrypt
- Access токен: 30 минут
- Refresh токен: 7 дней
- Все роуты кроме `/auth/*` требуют авторизации

## Ачивки и уведомления

После завершения сессии проверяются условия ачивок. При получении новой ачивки создаётся уведомление. Всё в одной транзакции.
