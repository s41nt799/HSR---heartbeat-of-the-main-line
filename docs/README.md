# Платформа обучения персонала через игровые сценарии

Платформа для обучения сотрудников транспортных компаний через интерактивные игровые сценарии. Пользователи проходят сценарии, принимают решения в условиях таймера, развивают компетенции и получают ачивки.

## Стек

- **Бэкенд:** Python 3.11, FastAPI, SQLAlchemy 2.0 (async), Alembic
- **БД:** PostgreSQL 15
- **Аутентификация:** JWT (access + refresh токены)
- **Контейнеризация:** Docker, Docker Compose

## Модули

| Модуль | Назначение |
|---|---|
| Авторизация | Регистрация, вход, обновление токенов |
| Сценарии | Просмотр каталога доступных сценариев |
| Сессии | Игровой движок: старт, узлы, выборы, таймауты |
| Аналитика | Прогресс по компетенциям, слабые зоны, история |
| Профиль | Данные пользователя, статистика прохождений |
| Ачивки | Справочник ачивок и прогресс получения |
| Уведомления | Уведомления о достижениях |
| Лидерборд | Топ пользователей по общему счёту |

## Запуск

### Требования
- Docker, Docker Compose
- Python 3.11+ (для локальной разработки)

### Переменные окружения

Создайте `.env` файл:

```env
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/gamification
SECRET_KEY=your-secret-key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
```

### Запуск через Docker

```bash
docker-compose up -d
```

### Применение миграций

```bash
alembic upgrade head
```

### Запуск сервера (локально)

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
