# ROADMAP.md — План развития после хакатона

## Приоритетные задачи (1 неделя)

1. **Backend интеграция**
   - Вынос `level` в `/auth/me` и `/profile` (клиентский fallback оставить как fallback)
   - Добавление `scenario_id` в `DebriefResponse`
   - Реализация `/profile/analytics`
   - Реализация `/challenges`
   - Реализация `/notifications`

2. **Дополнительные UI-экраны**
   - Страница `/docs` со ссылкой на Swagger/OpenAPI
   - Страница `/analytics` с детальной аналитикой компетенций
   - Страница `/challenges` с карточками челленджей

3. **Демо-режим**
   - Настройка `VITE_DEMO_MODE=true`
   - Длинные дедлайны (120 сек)
   - Предзаполненные сессии
   - Кнопка "Сбросить демо"

## Второе место (2-4 недели)

1. **Leaderboard improvements**
   - Фильтр по scope (company/depo/brigade)
   - Экспорт результатов

2. **Profile enhancements**
   - Компетенции с прогресс-барами
   - График progress_30d

3. **Accessibility**
   - Полная поддержка клавиатуры
   - screen reader поддержка
   - Контрастность цветов

## Долгосрочный план (1-3 месяца)

1. **Мобильная адаптация**
   - Полная поддержка мобильных устройств
   - Touch-интерфейс для выбора

2. **Интеграция с LMS**
   - xAPI (Tin Can) отчеты
   - SSO через CAS/OAuth

3. **Продвинутая аналитика**
   - Machine learning рекомендации
   - Прогнозирование риска провала

## Зависимости от внешних сервисов

- Backend API (все эндпоинты)
- Swagger/OpenAPI спецификация (для /docs)
- Redis для лидерборда (fallback из Postgres реализован)
